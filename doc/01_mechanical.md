# 01 - 机械装配与坐标系

## 整体布局

```
          前方 (+x)
            ↑
    ┌───────┼───────┐
    │  LF(0)    RF(1) │   ← 前腿对
    │                 │
    │  LB(2)     RB(3) │   ← 后腿对
    └─────────────────┘
```

- LF=左前(leg 0), RF=右前(leg 1), LB=左后(leg 2), RB=右后(leg 3)
- 从机器人正前方看：每条腿**左侧电机为 ID0，右侧电机为 ID1**

## 坐标系

右手系：
- **x**: 向前（正）
- **y**: 向下（正）
- **z**: 向左（正）

每条腿在髋关节处有自己的局部坐标系，x 指向机器人前方。

## 并联腿几何模型

每条腿是 5 杆并联机构：

```
       A (髋关节原点)
      / \
     /   \
  L1/     \L1
   /       \
  B         D
   \       /
  L2\     /L2
     \   /
      \ /
       C (足端)
```

| 参数 | 值 |
|------|-----|
| L1 = |AB| = |AD| | 130 mm |
| L2 = |BC| = |DC| | 260 mm |
| 减速比 | 6.33 |
| 最大伸展 | ≈390 mm |
| 最小伸展 | ≈130 mm |

### 关节角定义
- **θ1**: AB 杆与 x 负半轴夹角，由 motor0（ID0）驱动
- **θ2**: AD 杆与 x 正半轴夹角，由 motor1（ID1）驱动
- 输出端角度 = 转子角 / 6.33

## 零位

当前使用单圈绝对编码器（非多圈），断电重启后角度会折返。**上电前必须人工将腿放到零位/趴姿附近**。

零位检查使用单圈最短环绕误差，阈值转子侧 1.50 rad（输出端约 13.6 deg）。

| 电机 | 零位转子角 (rad) |
|------|-----------------|
| LF ID0 | 4.2988 |
| LF ID1 | 3.4371 |
| RF ID0 | 3.4235 |
| RF ID1 | 5.9666 |
| LB ID0 | 5.9979 |
| LB ID1 | 1.0314 |
| RB ID0 | 1.4003 |
| RB ID1 | 5.2892 |

## 足端工作空间（零位附近）

零位时足端坐标约为 x≈5mm, y≈228mm（四条腿略有差异）。正常工作时足端 y 范围 130~390mm。
