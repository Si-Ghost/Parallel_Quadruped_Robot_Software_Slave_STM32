# 07 - 未来规划

## 短期（当前优先级）

1. **Trot 步态调试**
   - 修复方向/对称性问题
   - 在起步架子上反复测试不同步长/抬腿/频率组合
   - 逐步过渡到完全自支撑行走

2. **增益调优**
   - 在 Trot 中对比 Kp=4.0/6.0/8.0 的表现
   - 平衡响应速度和过冲/振荡

3. **安全保护**
   - 添加过流/过热保护
   - 添加异常姿态检测（IMU）
   - 自动 Release 超时保护

## 中期

4. **IMU 集成**
   - 启用 UART4 的 IMU 传感器
   - 实现姿态反馈补偿
   - 身体姿态稳定控制

5. **串级 PID 控制**
   - 提高控制频率（>100Hz）或使用定时器中断驱动
   - 正确实现 1kHz 级联 PID
   - 与参考工程对标

6. **更多步态**
   - 爬行步态 (creep): 抬腿 40mm, 步频 1.4Hz
   - 跳跃步态 (gallop): 更高频率
   - 转向功能

## 长期

7. **遥控器集成**
   - 完善 ESP32 遥控帧解析
   - 实现实时步态速度/方向控制

8. **自主导航**
   - 添加视觉/深度传感器
   - 实现地形适应

9. **结构优化**
   - 3D 打印替代件
   - 减重设计

## 代码改进

10. **单元测试**
    - FK/IK 输入输出测试
    - PID 参数验证

11. **配置参数化**
    - 步态/增益等参数存入 EEPROM
    - Web UI 支持实时调参

12. **OTA 升级**
    - ESP32 OTA
    - STM32 通过 ESP32 间接升级
